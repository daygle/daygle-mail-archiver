How alerts work

Alert generation logic

Alerts and email notifications are handled separately:

  1. Trigger enabled: the event creates an in-app alert using the configured severity.
  2. Email delivery: enabled, eligible users receive an email when their notifications are enabled and SMTP is configured.
Note: Email notifications are sent only to enabled users with the manage_global_settings permission and a configured email address.

Alert hierarchy

  • Alert TriggersSpecific events with customisable severity
  • User SettingsEmail notification delivery preference
  • Email SettingsSMTP configuration for delivery
