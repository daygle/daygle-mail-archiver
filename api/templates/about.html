About Daygle Mail Archiver

A Deterministic Email Archiving System

Daygle Mail Archiver is a comprehensive email ingestion and archiving system designed for long-term retention, auditability, and operational reliability. It ingests emails from multiple sources and provides a clean, modern interface for browsing, managing, and analyzing archived email data.

Key Features

  • Multi-Source Support: IMAP/IMAPS, Gmail API, Office 365 Graph API
  • Automatic Archiving: Continuous polling with delta sync
  • Full-Text Search: Search across subjects, senders, and recipients
  • Raw Email Storage: Complete RFC822 format with compression
  • Retention Policies: Automatic purging based on configurable rules
  • Virus Scanning: Integrated ClamAV with configurable actions
  • User Management: Multi-user system with role-based access
  • OAuth2 Integration: Secure authentication for Gmail and Office 365
  • Dashboard Analytics: Visual charts and customizable widgets
  • Advanced Reporting: Email volume trends and system health
  • Email Alerts: Configurable SMTP notifications
  • Audit Logging: Complete audit trail of all actions

Built with explicit, maintainable configuration and modular backend logic, Daygle Mail Archiver ensures predictable behavior across all environments while providing enterprise-grade email archiving capabilities.
