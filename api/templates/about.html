Overview

Daygle Mail Archiver is a deterministic email archiving system for long-term retention, auditability, and operational reliability.

It ingests emails from IMAP, Gmail API, and Office 365 Graph API, then provides a clean interface for browsing, managing, and analyzing archived data.

Built with explicit configuration and modular backend logic, it is designed for predictable behavior across environments.

Key Features

  • Multi-source support: IMAP/IMAPS, Gmail API, Office 365 Graph API
  • Automatic archiving: continuous polling with delta sync
  • Full-text search: query subjects, senders, and recipients
  • Raw email storage: complete RFC822 format with compression
  • Retention policies: configurable automatic purging
  • Virus scanning: ClamAV integration with configurable actions
  • User and role management: RBAC with granular permissions
  • Dashboard and reports: analytics, trends, and system metrics
  • Audit logging: complete trail of user and system actions
